# 聊天图片拖拽与原图下载

2026-10-29，本地实现。

- 从系统文件管理器将 PNG/JPEG/WebP/GIF 图片拖到聊天室卡片，显示落点提示；松手后进入既有附件预览，点击“发送”才发出，可附文字，失败保留附件与文字。
- 每次一张、最大 20 MB；多张、非支持格式、发送中或聊天关闭时提示原因，并保留原有待发送内容。拖到卡片之外不会导致浏览器跳转到文件。
- 每张聊天图片下方提供“下载原图”。使用带匿名会话鉴权获取的原始 Blob 下载，保留原文件名，不经过 Canvas、缩放或格式转换。显示尺寸仍由 CSS 控制，继续不展示冗长图片名称。
- 附件沿用现有可见期及鉴权，下载按钮不会扩大访问范围。

验证：`node test-chat-images.cjs` 通过拖拽状态/格式/大小/忙碌/关闭/导航拦截及真实附件渲染函数测试。`npm test` 使用隔离服务器验证另一匿名会话下载，1200×700 PNG 字节与上传文件完全一致，匿名未认证及过期访问被拒绝。

另在仅监听 127.0.0.1 的隔离服务实测浏览器“下载原图”，下载内容与合成源文件逐字节一致；原图显示和按钮正常，控制台无错误。未向正式聊天室发送测试消息。拖拽事件状态由自动化覆盖，未进行系统文件管理器原生拖拽的人工验收。

用户已要求 commit、push 和内网上线。本次发布包含图片拖拽、原图下载及此前的滚动适配，仅更新本地/内网，不更新云端，不覆盖其他游戏修改。发布提交与内网文件核验结果存于本机 `.publish/chat-images-lan-deployment.json`。
