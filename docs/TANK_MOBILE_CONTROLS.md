# 坦克大战手机操作

2026-10-26：用与蔬菜冒险一致的圆形摇杆、操作按钮替换原方向按钮区。左侧拖动控制四向移动，右侧大按钮按住连续开火、小按钮按下释放主动技能；允许三者多指同时操作。主动技能仍由既有装备、冷却规则约束。

摇杆具有中心死区与行程限幅，仅接受一个控制指针。松手、系统取消触摸、丢失指针捕获、暂停、窗口失焦、进入后台、阵亡、游戏结束或视口尺寸变化时清除对应输入。触摸与键盘状态独立，保留方向键/WASD、空格、E、P。

控件沿用暖纸色与叶绿色，在战场下方预留区域，不遮挡地图；适配窄屏和安全区。桌面宽屏鼠标环境继续隐藏触控区。

验证：`npm run test:tank` 包含原有 14 组玩法回归和触摸输入测试（四向/死区、限幅、多指移动+开火+技能、指针取消/捕获丢失、重置、禁用技能）；聊天/附件/TOTP 回归通过。390×844 浏览器视口检查布局、拖动与开火，控制台无错误。多指同时操作由自动化输入测试覆盖，尚未进行实体手机触屏验收。
