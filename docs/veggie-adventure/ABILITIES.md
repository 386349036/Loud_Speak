# 能力与战斗规则 v1

本文件是待实现规格，数值属于可测试的初始基线，不代表已经完成玩法调试。

## 主角

| 状态 | 能力 | 受伤 |
|---|---|---|
| 基础 | 移动、助跑、单次可变高度跳跃、踩踏、顶奖励砖 | 死亡 |
| 成长 | 基础能力、碎普通砖、蹲下 | 回到基础 |
| 辣椒 | 成长能力、弹跳火弹，同时最多2枚，发射间隔0.25秒 | 回到基础 |
| 杨桃叠加状态 | 持续10秒，接触消灭普通敌人，免疫普通接触与普通敌弹 | 不免疫掉坑、熔糖、压死；不接触秒杀首领 |

基础碰撞框12×14逻辑单位；成长/辣椒12×28，蹲下12×14。脚底中心为统一锚点。
成长时空间不足保持蹲姿；蹲下不可发射；低顶下不能强制站立。
跳跃不提供二段跳。水下按跳跃键上划，不沿用陆地踩踏伤害。
受伤保护1.5秒；普通死亡0.7秒后回检查点。
获取营养萝卜：基础变成长；其他形态保留并得1000分。
获取辣椒：基础先成长，成长变辣椒，已有辣椒保留并得1000分。
重复杨桃将剩余无敌时间重置为10秒，不累计；闪烁预告最后2秒。
金种子每枚100分；原额外生命奖励替换为金萝卜，奖励1000分，不提供生命或新形态。

检查点保存当前形态、得分、收集状态与关卡剩余时间；死亡回滚到检查点快照，临时无敌清除。
奖励砖和敌人也恢复检查点世界快照，确保不会累计重复奖励。
首领入口为检查点；重试恢复入口快照，首领、敌弹、机关全部重置。
无限重试，保留倒计时与超时死亡；不沿用生命耗尽游戏结束。

## 普通敌人交互

- 陆地踩踏要求玩家下降且上一帧脚底不低于敌人顶面；侧面接触不能误判为踩踏。
- E01可踩、可火弹击败。E02被踩缩壳；静止壳可踢，运动壳再次从上方踩中后停止。
- E03沿用壳状态，但抗火。E04不可踩，可用火弹或运动壳击败。
- E05、E06在水下不能踩；E12空中可以踩。E07可踩、可火弹或运动壳击败。
- E08不可踩，缩回时无伤害碰撞，伸出时可火弹击败。E09可踩或火弹击败。
- E10可踩落、抗火；发射器不是可攻击敌人。E11首次踩去翼并变为E02，火弹可直接击败。
- 运动壳可击败普通敌人，包括E03；两个运动壳相撞双方销毁。静止壳8秒后摇晃1秒再恢复巡逻。
- 踢壳者仅享有0.15秒离身保护，之后反弹壳可伤及自己。
- 装饰叶片、翅膀、根须不额外扩大碰撞体。带刺与抗火必须有形状和命中特效提示。
- E09最多维持3只自身生成的E04；E10发射器近距24逻辑单位不发射。
- 敌人投射物统一登记，不能通过“像道具”外形误导玩家。

## 首领统一规则

8位首领各3格生命。攻击至少0.5秒预兆，只在设计卡约定破绽中可伤。
踩中弱点扣1格；同一次破绽内3枚火弹扣1格，未满3枚在破绽关闭时清零。
扣血后立即关闭弱点并进入1秒受伤保护，清除当前直接重叠的攻击物；每次破绽最多扣1格。
普通关闭状态下火弹出现弹开反馈；杨桃不能跳过弱点条件。
首领受击后通过平移/退后保持玩家落脚区安全，不将玩家弹进墙体或坑。
每个竞技场必须有基础形态能到达的弱点路线；需要垫脚的首领配置不可破坏矮台。
最后一格只能提高攻击间隔或移动节奏，不能缩短最低预兆和卡片规定的弱点时长。
B04采用水池与岸台，B07共用生命且只允许单头攻击，避免无解叠加。
首领失败入口重试；获胜清场、解除封锁、播放离场动画并进入通关流程。

## 非角色资产

道具：营养萝卜、辣椒、杨桃、金种子、金萝卜。
敌弹：玉米粒、籽弹、土块、落刺、爆裂种子。玩家火弹单独分类。
机关：旋转辣椒火链、熔糖喷泉、升降藤台、坠落平台、茄子发射器。
