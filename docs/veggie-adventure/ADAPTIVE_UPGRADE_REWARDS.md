# 升级方块按主角状态生成道具

2026-10-26。32关共207个升级奖励方块统一在**被撞击、释放道具的时刻**读取主角当前形态。

| 当前形态 | 出现的道具 | 拾取后 |
| --- | --- | --- |
| 初始芽豆 | 萝卜 | 成长芽豆 |
| 成长芽豆 | 辣椒 | 辣椒芽豆，可发射火弹 |
| 辣椒芽豆 | 辣椒 | 保持最高形态，获得原有1000分 |

地图中原来写作萝卜或辣椒的奖励均表示“升级”，实际释放不再固定跟随地图类型。同一坐标的方块可因主角形态不同而产出不同物品。积分和星星保持原奖励。

道具出现后保持已生成的类型，不在主角受伤或升级时变换图像；拾取保留既有逐级成长规则。受伤回到初始形态后撞击尚未使用的升级块会出萝卜；死亡重生从初始形态重新判定。所有方块仍只出物一次，奖励面、砖块破坏、道具运动与拾取、脚底锚点、存档结构均沿用原规则。当前地图没有预先摆放在地面的萝卜/辣椒。

逻辑集中在 `Game.spawnBlockItem`，可破坏砖及兼容旧奖励方块共用。185项回归通过，检查覆盖207块×3形态、同坐标实际向上跳撞、两类方块、拾取成长与最高等级、积分/星星不变、出物后受伤、存档及死亡重生；本地HTTP运行模块与工作区一致。仅本地更新，未做本轮浏览器视觉或人工游玩验收。
