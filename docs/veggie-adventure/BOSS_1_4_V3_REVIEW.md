## 战场配置

竞技场仍为x=1424～1712，地面连续，无战场内死亡坑。增加三个固定单向落脚点，暂不加入强制伤害机关，先验证路线与招式本身的配合。

| 落脚点 | 位置 | 功能 |
|---|---|---|
| 左侧低台 | x=1456，y=176，宽48px | 躲地面波、落点诱导、下撤 |
| 中央高台 | x=1568，y=160，宽48px | 躲冲撞、向两侧发起空中反击 |
| 右侧低台 | x=1664，y=176，宽32px | 右侧换位与追击目标 |

平台不会塌落。玩家向上穿过、下降落台；下方向+跳跃可主动落下。三种体型共用运动能力，单向平台不会强迫大体型蹲伏穿行。旧战前检查点会补入新增平台，保留原分数和关卡完成记录。

## 首领行为与公平性

- 首次落震固定，先展示预警及反击窗口。
- 远距离偏向锁定跳扑，高台近距离偏向瞄准抛射，近距离地面且掉血后可选择冲撞；避免连续使用相同招式。
- 跳扑可追击玩家所在高台，并在预警时锁定落点；后续移动不会改变已预警的目标。
- 抛射按预警时的位置和水平速度做有限预判，不在飞行途中追踪玩家。常态两枚，低血量三枚，有间隔。
- 冲撞显示地面范围，可以跳过或登台躲避；冲撞结束后提供反击窗口。
- 常态预警1.25秒，低血量1.05秒；常态弱点至少3.2秒，低血量至少2.8秒，较远反击距离可延长至4秒。
- 低血量缩短巡逻停顿并增加抛射数量，仍保留预警和反击。受伤、死亡时清空危险物；每次弱点只扣一格血。

## 浏览器验收过程

使用本地3210游戏页面，正常按钮、方向键、空格、暂停与检查点重试。没有注入坐标、无敌、首领血量或通关状态。只读QA信息用于记录位置、阶段和血量。

1. 第一轮：从检查点进入，在左侧低台避开落震；停留高台后首领锁定该台并跳扑。下+跳落回地面、向中间换位成功。发现平台与头部齐平时的踩踏遮挡，随后修正。观察了对高台的瞄准抛射。
2. 第二轮：中央台穿下踩第一击；在地面诱导近身冲撞，登中央高台避开，再跨至另一侧踩第二击；避开抛射后踩第三击。保持成长形态击败首领，23710分、386秒到达出口。这轮发生在最后两项弹道修正之前。
3. 第三轮：最终弹道复验时，过早跳入仍处于攻击阶段的首领身侧，基础形态死亡并恢复检查点。该次失败保留在记录中，不能记为通过。
4. 最终轮：完成弹道及边缘瞄准修正后重新进入。中央台穿下踩第一击；在高台横向换位避开瞄准抛射，从台边落下踩第二击；右台受到锁定跳扑后下撤，撤退过深发生一次接触受伤，退回基础形态。随后重新登中央台，向右跳起踩中第三击，击败首领并进入出口。最终23730分、388秒、4/32，boss hp=0，mode=won。

上述分数包含此前关卡继承与战前检查点分数。多次暂停观察，剩余时间不等于连续操作耗时。此次最终轮覆盖完整首领战及出口，关卡前段沿用此前实机结果，并再次通过全关三形态地形检查。
