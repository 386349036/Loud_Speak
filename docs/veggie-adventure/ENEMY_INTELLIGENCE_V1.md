## 行为规则

单位为游戏像素和秒。决策只使用当前位置、可见速度、地形与星光光环，不读取玩家按键。出生点附近活动范围及地图显式巡逻边界继续生效。

| 敌兵 | 新行为与限制 |
| --- | --- |
| E01 香菇巡逻兵 | 同层104像素内观察0.18秒，停步预警0.3秒，然后锁定方向追击0.75秒，速度24；休息0.8秒后恢复巡逻。 |
| E02 卷心菜壳兵 | 同样先观察再追击，速度28；缩壳、踢壳、踩停、醒转仍按原规则，由玩家控制的滚壳不受追击边界限制。 |
| E03 核桃甲虫 | 追击速度18，保留抗火、缩壳和滑壳特征；不会因为智能增强而获得额外生命。 |
| E04 刺栗守卫 | 落地后才开始观察，追击速度16，保留展开动作与不可踩特征。 |
| E05 莲藕水母 | 每次两秒脉冲只观察一次同水域玩家；前0.5秒以速度24靠近锁定横坐标，范围不超过出生点左右32像素，其余时间缓慢漂移。 |
| E06 椒鱼 | 只对同水域、96像素范围内目标观察0.25秒；预警0.45秒后横向拦截0.8秒，速度30，随后用1.2秒返回巡游。锁定目标在出生点左右40像素内。 |
| E07 玉米投手 | 观察0.3秒后，过近时后退、过远时靠近，目标间距64至96像素；移动不超过出生点左右32像素。0.6秒举臂预警开始时锁定目标与投掷方向，最多预判20像素；三连抛射后恢复，不在出手瞬间重新瞄准。 |
| E09 棉花云牧者 | 在出生点左右64像素内缓慢跟随，速度18，最多预判20像素；0.6秒投放预警期间停住，锁定投放列并显示地面标记。生成及投放动作期间不会随玩家转向平移。保留近距离生成保护与最多3只子兵。 |
| E11 飞翼卷心菜 | 与椒鱼相同的预警、锁定、短距离横向拦截，速度32；保留原有高度轨迹。脱翼后清除空中决策，落地重新观察，不能继承一次无预警的地面攻击。 |
| E08 豌豆捕虫株 | 保留近距隐藏、伸出预警、危险停留、缩回的固定周期。 |
| E10 茄子炮弹兵 | 保留炮口预警、贴身停火和固定水平轨迹。 |
| E12 跃水椒鱼 | 保留水面预警、固定跃出轨迹和入水停顿。 |

四类地面敌兵共同规则：视线被实体阻挡或高度差超过32像素时不主动追击；追击前检查通往目标的连续地面，隔坑不反复预警。移动前探测前方支撑、墙与巡逻边界，危险处停步0.55秒再折返。没有显式边界时，活动限制在出生点左右64像素。看到星光无敌状态时，下一轮预警后朝远离玩家方向短暂退让，速度24。

追击和拦截开始后方向或目标锁定，留出躲避与反击机会。停止时步行动画停在站立帧，移动时动画节奏随速度变化；预警显示感叹号。云牧者地面标记表示投放列，子兵仍有横向下落运动，因此不表示最终落点精确命中该列。
