# 发现后的连续攻击与昏厥壳体

2026-10-26，本地修改。解决试玩中“出现发现叹号但没有继续接近”和“缩壳仍然清醒”的反馈，并补齐食人花预警被缩地周期中断的问题。本页取代旧智能说明中的短追击、休息和锁定旧位置规则。

## 原因与新行为

旧版香菇只走0.75秒，实际约18px，随后休息；卷心菜/核桃冲刺32px后休息1秒。发现预警、攻击时段、休息及两处巡逻坐标限制叠加，往往无法走到主角身边。食人花在显露后段不再寻找目标，预警与固定缩地时钟也没有互斥。

| 对象 | 当前规则 |
| --- | --- |
| 香菇 E01 | 可见且同一连续地面内观察0.18秒后，显示“！”的同时向主角移动；持续追击速度64px/s，主角换边便修正方向，没有固定休息段。 |
| 卷心菜 E02、核桃 E03 | 首次发现仍立即朝当时方向冲刺32px、速度128px/s；冲刺结束直接持续追击，速度分别72、60px/s。2秒技能冷却仅限制再次冲刺，不限制接近。 |
| 刺栗 E04 | 发现时发射前、上、前上45度三根尖刺，并以56px/s接近。0.45秒发射动作期间持续移动，2.4秒技能冷却期间继续追击。 |
| 飞翼卷心菜 E11 | 观察0.25秒后边显示发现提示边追击当前主角位置；水平112px/s、垂直最高80px/s，不再攻击一次旧落点就休息返航。 |
| 椒鱼 E06 | 同水域观察0.25秒后，水平64px/s并上下接近当前目标。水池边界、池底、实体墙仍参与限制。 |
| 食人花/捕虫株 E08 | 伸出时可记住目标；整个显露窗口都可发现主角，包括最后一刻。吐弹预警0.35秒、吐弹后收招0.3秒期间暂停缩地时钟，必先出弹再缩地。每次显露最多一发，方向在承诺攻击时锁定，豌豆96px/s、存在2秒，参与实际伤害与墙体碰撞。 |

四类地面追兵初始观察范围104px/脚底高度差32px，交战后扩大为208px/96px。短暂失去视线时最多追到最后所见位置1.25秒，随后走回巡逻范围；不读取玩家按键。星光保护仍使地面小兵退让。空中追兵也在失去目标后平滑返航，返航途中不因远距离停更新而悬停。

巡逻边界现在只约束闲逛。交战仍检查真实连续地面、墙体、前方支撑与关卡边缘，后续长关的坑前后128px落地缓冲继续生效。早期短岸段若容不下两侧128px，或原敌人就出生在缓冲区内，交战改用6px实际崖边防护；不会因此越坑、穿墙或瞬移。墙被破坏后可立即恢复逼近。

玉米、云牧者、固定水生植物继续承担远程/定点攻击职责；水母保留脉冲移动，跃水鱼保留固定跃出轨迹。本轮没有将这些类别改成统一地面冲撞。首领仍只在弱点期扣血。

## 昏厥视觉与规则

内置 image_gen 分别生成E02/E03/E04透明源图，各12帧，归档在 `art-source/veggie-adventure/animations/stunned-v1/<ID>/generated.png`；同目录 `prompt.txt` 保留完整提示词。运行图集位于 `public/games/veggie-adventure/assets/animations/stunned-v1/`，继续使用原角色ID和比例。

被踩立即显示闭眼/X眼的缩壳，随后保持昏厥呼吸帧；踢动后的滑壳也保持昏厥表情。第8至9秒播放一秒醒转，再恢复正常步行。E04新增独立缩壳/昏厥/滑行/醒转片段，避免借用正常落地展开或下落表情。正常行走、受击及E04普通下落像素保持原样；逐帧脚底锚点重新校准。提示文字区分“昏厥·护壳”“昏厥·滑行”和“醒转”。

防护玩法不变：昏厥壳体被踩不掉血，也不伤主角；侧踢滚动、顶踩停止滚动、9秒恢复、血量耗尽退场均保留。醒来时以当前所在位置重新建立巡逻，不拉回旧巡逻点。飞翼首次被踩仍先脱翼，之后按地面壳兵规则处理。

重建：`node tools/veggie-adventure/build-stunned-animations.cjs`。两条旧动画构建流程均会重新应用本层修正，防止后续重建恢复清醒壳脸。
