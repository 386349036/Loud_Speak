# 1-3 可破坏高路实验

2026-10-27，仅修改1-3的布局，使用既有石砖PNG和角色素材。关卡仍为1536单位，起点、出口、限时保持不变。

## 路线设计

保留地面路线，增加三段可选择的上层支路。每段由176、128、80三个高度的可破坏方块台面组成，阶梯之间高度差32/48/48，起跳和落地均使用现有主角物理；三种成长形态都可通过。相邻上层之间保留32单位的净空。

新增51块砖，总计58块；新增3名高处巡逻敌人，总计6名敌人，原有地面香菇及两只飞行敌人保留。每条高路有两枚种子奖励，中段高路额外设置一个动态成长奖励方块，仍按主角当前状态决定胡萝卜/辣椒/积分。

原地图短坑密集，无法同时容纳分层路线和两侧8格禁放方块区。因此填平672–720、1248–1296两处短坑，形成高路下的安全地面；保留416–464、976–1024两处48单位跳坑。新增方块及高处巡逻区均避开剩余坑两侧128单位。原地面香菇的巡逻右界收紧至848，防止进入坑前缓冲区。

## 互动规则

- 上层方块可站立，也可从下方顶碎，没有新增不可破坏的隐形平台。
- 三段高路都有阶梯入口和落回地面的空间，不是强制路线；地面短跳路线无需成长或破砖即可通关。
- 高处敌人使用现有巡逻与发现主角后的追击；活动限制在砖台范围内。脚下路线被破坏时正常掉落到下层，不悬空、不转成飞行状态。
- 即使所有方块都被打碎，仍可沿地面完成本关。
- 记录旧1-3布局用于存档迁移，保留已完成关卡、积分结算和重生规则。

## 验证和使用

273项自动回归通过。本轮新增检查包括：三形态×三支路共9组真实输入逐层起跳、完整砖台落脚和返回地面；三形态在完整布局及全部砖块损毁后共6组地形通关；三名高处敌人巡逻/追击及砖台损毁后掉落；坑缓冲、奖励不重叠、旧存档迁移、工具重复运行不继续叠加。
