# 后续21个普通关卡分层高路

2026-10-27，本地实现。范围为2-1至8-3的21个普通关卡；八个Boss场地和1-3实验地图保持各自设计。

新增56条可选支路、664块可破坏砖、56名高处敌人和168枚种子。每世界首个普通关卡增加两条，其余普通关卡各三条。每条由低踏步、中层长台和顶层短台构成；通常高度176/128/80单位，依旧地形调整为160/112/64或144/96/48。2-2的三处入口从水面游上第一阶。

保留地面主路、地图长度、地面平台、水域、机关、移动平台、出口、旧敌人及原有奖励内容。55块原奖励砖并入新高层，解除重叠和卡顶；受影响的原种子移出实体砖。高路避开真实深坑前后128单位及机关完整范围，入口与旧阶梯保持净空。破坏整条支路后可落回地面继续前进。

不同世界在高层布置核桃、卷心菜、玉米、香菇或刺栗。巡逻范围限制在实际砖面；脚下砖消失后按正常重力落下。顶层起跳加入最多96单位向上镜头跟随，主角始终保留顶部视野；不改变跳跃物理、Boss镜头或选关房。
