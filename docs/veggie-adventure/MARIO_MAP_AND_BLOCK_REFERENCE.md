## 2. 变大是否提高跳跃能力？

**不会。** 原版说明书明确说明小马里奥和超级马里奥跳跃高度相同；按住A的时长及起跳速度会改变跳跃。火焰形态也使用同一套普通跳跃参数，没有额外跳跃加成。

来源：[原版说明书转录，How to play / Pointers](https://www.world-of-nintendo.com/manuals/nes/super_mario_bros.shtml)；[任天堂官方电子说明书](https://www.nintendo.co.jp/clv/manuals/en/pdf/CLV-P-NAAAE_en.pdf)；[原版程序反汇编](https://raw.githubusercontent.com/nwoeanhinnogaehr/smb-assembler/master/smbdis.asm)。反汇编中起跳参数按水平速度选择，PlayerSize在该处改变的是跳跃音效。

| 形态 | 相同条件下的跳高、跳远 | 对摆方块的影响 |
|---|---|---|
| 小马里奥 | 基准 | 身体较矮，上方余量较大 |
| 超级马里奥 | 与小马里奥相同 | 身体变高，容易提前顶到低天花板；可以破坏普通砖块 |
| 火焰马里奥 | 与超级马里奥相同 | 净空按大体型检查，火球能力不增加跳跃 |

头顶能碰到更高的砖，并不代表脚底上升得更高。跨坑必须看脚底轨迹和实际碰撞体，不能用精灵图片总高度替代。

## 3. 跳跃数值：统一测量口径

按1格=16像素计。下表是依据上述反汇编写出的独立数值模型结果，**不是任天堂官方公布数值，也不是模拟器逐帧实测**。适用于普通陆地、全程长按A、起跳前达到指定速度、同高落地、无顶头、无弹簧和踩敌反弹。小/大/火焰三形态共用此表。

| 起跳状态 | 固定水平速度 | 脚底最大上升 | 回到起跳高度的水平位移 |
|---|---:|---:|---:|
| 原地，全程不横移 | 0 | 约66px / 4.13格 | 0 |
| 已达普通行走速度 | 1.5px/帧 | 约71px / 4.44格 | 约87px / 5.44格 |
| 已达奔跑速度 | 2.5px/帧 | 约83px / 5.19格 | 约142.5px / 8.91格 |

模型保留整数/小数累积、上升与下降两档重力、下降限速，初始位置小数为零；落地按首次回到或越过起跳高度计。因此距离带有帧量化误差。没有复现完整水平加速、碰撞检测或边缘判定，不能将8.91格直接认定为可安全跨越8.91格宽的坑。起跳位置、碰撞盒边缘、落台高度、短按A都会改变结果。

可复算：`node tools/veggie-adventure/reference-smb-jump.mjs`。对应源码标签：JumpMForceData、FallMForceData、PlayerYSpdData、JumpSwimSub、ImposeGravity。

## 4. 方块设置规则：本项目建议，非任天堂官方规则

| 项目 | 建议执行规则 | 原因 |
|---|---|---|
| 必经路径 | 小体型的最弱跳跃能力与大体型的最大身体尺寸分别验算 | 只测一种形态会漏掉跳不到或顶头问题 |
| 坑前后区域 | 按用户要求，坑前8格、坑后8格及坑上方跳跃空间不设实体方块；合并相邻坑的禁放区 | 避免起跳、空中和落地时顶头；8格是本项目规则，不是原版规则 |
| 全高跳跃净空 | 天花板下沿至脚底地面的距离至少为“最大身体高度+最大跳高+余量” | 大角色身体顶部也要随跳跃上升 |
| 平地通道 | 净高必须大于最大碰撞体高度，并留余量 | 能站进去不等于能在里面跳过去 |
| 坑宽 | 必经坑采用最弱形态可重复达到距离的约65%—75%作为初始设计预算，再实测 | 给提前起跳、手机操作和速度未满留空间；这不是原版统计规律 |
| 高低平台 | 落台越高，可用水平距离越短，逐段计算并测试 | 同高跳远数据不能套在上坡跳跃上 |
| 落脚区 | 初期落台建议至少3格宽；主要落点不放敌人、低顶或立即接下一坑 | 给玩家恢复和选择下一动作的时间 |
| 台阶高度 | 主路线采用小形态可达的高度，并保留明显余量 | 升级不应变成通过主路线的必要条件 |
| 奖励方块 | 放在安全地面上方，且小体型也能顶到；不能侵入跨坑轨迹 | 领奖励不能破坏必经路线 |
| 可破坏方块 | 破坏后仍须能继续通关；避免唯一落脚点被毁后形成软锁 | 全可破坏设计需要额外检查破坏后的地图 |
| 金币/积分 | 与实体方块的完整矩形检测重叠；奖励沿真实可达轨迹布置 | 仅检查中心点会漏掉嵌入方块的情况 |
| 隐藏方块 | 不放在必经跳坑的上升路径或预期落点附近 | 不用不可预见的顶头制造失败 |
| 升级道具 | 放在可容纳大体型的区域，升级后不夹进砖块或顶棚 | 形态转换本身也有通行风险 |
| 动态平台与门 | 测试多个相位、开闭状态，并提供安全等待位置 | 静态地图通行不代表运行时可通过 |
| BOSS区域 | 各形态均有完整躲避路线；预警期间有足够移动空间 | 预警可读也需要地形允许玩家执行躲避 |

## 5. 与当前蔬果游戏的对照（运动实验更新）

2026-10-25完成多轮运动实验及第一世界实际游玩，详见[MOTION_PLAYTEST_20261025.md](MOTION_PLAYTEST_20261025.md)。体型升级不增加跳跃，起跳按当时速度选择参数。普通地面移动约1秒达到112px/s。

| 状态（所有形态相同） | 长按跳跃的脚底上升 | 同高位移 |
|---|---:|---:|
| 原地不横移 | 62.83px / 3.93格 | 0 |
| 起跑半秒，再持续向前 | 70.89px / 4.43格 | 83.53px / 5.22格 |
| 起跑1秒达到满速 | 78.69px / 4.92格 | 96.13px / 6.01格 |

这是实际Game物理、1/120秒步长的平地模拟值，不是安全坑宽。上升重力625px/s²，下落重力1400px/s²，下降限速350px/s，因此不能再使用同重力公式T=2v/g估算完整滞空。

小体型碰撞高度14px，大体型28px。按最大跳高78.69px加8px余量，完整跳跃净空分别为100.69px（7格）、114.69px（8格）。当前建议大体型必经高跳区域按**8格垂直净空**设计；旧6格建议已被本轮运动调整替代。

继续遵守坑前后各8格禁放方块，普通必经坑先按3—4格宽设计；起跑与刹车空间也要检查。初期相邻平台上升高度先保守控制在2格左右，兼顾非满速起跳。当前跳高接近原版4—5格范围，但水平速度和滞空仍为本项目参数，不能直接照搬原版地图。

第一世界四关已通过本轮键盘实际游玩；三形态地形模拟12/12通过。完整人工游玩只覆盖实际记录中的形态变化，不能据此声称三形态各自完整通关或手机多指已验收。
