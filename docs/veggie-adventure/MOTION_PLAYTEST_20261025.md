# 第一世界运动调整与实际游玩记录

日期：2026-10-25。目标：从1-1多轮调试，保留一秒自动起跑，向初代马里奥的长短跳、惯性和落地节奏靠近。并非原版物理逐帧复刻，最高水平速度仍为本项目112px/s。

最终规则：地面加速度112px/s²，约1秒达到112px/s；地面松开制动320px/s²，反向制动448px/s²；空中有方向时加速度224px/s²，无方向时保留水平惯性。蹲行和游泳沿用各自速度与控制。上升重力625px/s²，下落1400px/s²、下降限速350px/s，起跳参数按速度锁定；松开跳跃截断上升速度。三种体型同条件轨迹一致。边缘起跳容错75ms，落地前按键缓存100ms；不允许空中二段跳。动画仍使用run素材，节奏随移动速度变化。

## 实机发现、修复与复验

1. 第2轮之前在1-1第三坑后落地与卷心菜接触死亡，截图确认敌人在落地缓冲区。后将卷心菜巡逻限制在x=1136～1200，末段蘑菇限制在1376～1440；以正常键盘重新从起点通关，第三坑落地安全。
2. 第1轮松开制动距离约27.5px，收紧到约19.1px，保留惯性并提高反向响应。实机通过反向取道具、坑前定位和连续起跳。
3. 1-4竞技场扩大后，旧固定镜头只显示左侧256px，角色退到x=1685时离开屏幕。改为在竞技场边界内跟随玩家；从检查点重新进入，验证x=1695处角色、跳扑落点及首领都可见。
4. 实际观察首领落震、定点跳扑和种子抛射。落震后成功踩第一击；跳扑从约x=1551移动至1664，提前左移成功躲避后踩第二击；种子阶段退开弹道，再以基础形态踩第三击。第二击后的撤退发生一次接触受伤，最终仍完成战斗；不能称无伤通关。
5. 预警PNG与中文说明、弱点4秒倒计时和血量递减均在浏览器可见。首领死亡后危险物清空、出口开放，页面显示4/32。

## 方块摆放经验

- 跨坑轨迹与敌人巡逻范围一起检查；只清空静态方块仍可能在落点遭遇巡逻敌人。
- 新版最大脚底上升接近79px；大体型28px，加8px容差，完整高跳顶部建议至少留8格净空。旧6格净空建议已不足以容纳本轮最大跳跃。
- 坑前后8格无方块继续执行。原地跳和满速跳不同，不能假定玩家每次起跳都有满速。
- 同样要保留足够的刹车空间；1秒起跑和约0.35秒刹车会改变检查点后、道具旁及敌人前的操作节奏。
- 扩大首领场地时同步检查镜头、落点预警与出口显示，而不仅是碰撞边界。

最终63项自动检查通过，包含三形态轨迹、短跳、惯性、制动、起跳缓存、敌人巡逻与竞技场镜头。日志：.publish/motion-final-tests.txt。第一世界三形态地形探测12/12通过，涵盖每组12种起跳/障碍探测参数；它排除了战斗和机关危险，不等于三形态逐关人工通关。当前仅本地更新，其他世界的物理手感和地图需后续回归。
