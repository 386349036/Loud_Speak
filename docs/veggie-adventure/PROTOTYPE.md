# 1-1可玩样板

此文为历史样板交付记录。最新版本已扩展为八世界32关，见 [CAMPAIGN.md](CAMPAIGN.md)；下文的“仅1-1”与素材数量是当时状态。

## 启动

在项目根目录运行 `node tools/veggie-adventure/serve.cjs`，打开 http://127.0.0.1:3211 。此服务仅监听本机，不启动聊天室或修改首页。若既有站点运行，也可访问其 /games/veggie-adventure/ 路径。不要通过file://打开游戏，模块和素材清单需要HTTP。

## 实现范围

16单位地形格，固定120Hz逻辑步进；基础碰撞12×14，成长12×28，脚底锚点。独立关卡文件位于public/games/veggie-adventure/levels/world-01/level-1-1.mjs。

已实现移动/助跑、按住变高跳跃、顶奖励箱、成长碎砖、低顶蹲姿、香菇踩踏、卷心菜缩壳/踢壳/停壳/恢复、辣椒弹、杨桃无敌、计分、倒计时、死亡回滚、检查点、本地保存和终点。键盘与触屏按钮可操作，失去焦点自动暂停。

奖励物会沿箱顶移动并落下，避免基础形态够不到；检查点快照保存箱子、敌人、收集状态、分数与剩余时间，死亡后清除临时无敌及火弹。

## 素材

使用内置生图工具生成样板专用主角/物件图集，按4×4单元切分，以Alpha范围归一化并固定脚底锚点。原图与提示词保存在art-source/veggie-adventure/working/prototype；构建脚本为tools/veggie-adventure/build-prototype-assets.cjs。

运行清单登记34项：16个主角姿态、16个物件/敌人姿态、2层森林背景。48×48或48×96画布，nearest缩放。属于prototype-runtime，visualVerified=false，不等同最终动画资产。当前步行仅两个交替姿态，辣椒蹲姿复用压缩立姿；火弹与叶旗为简单运行绘制。音乐音效未制作。

## 非可视化检查

运行 `node tests/veggie-adventure/game.test.mjs` 与 `node tests/veggie-adventure/assets.test.mjs`：16项逻辑测试和2项素材/HTTP检查通过。覆盖跳跃差异、不可二段跳、短坑跳距基线、奖励单次触发、道具可达、低顶、受伤、壳体、弹数限制、死亡回滚、检查点、超时、出口和存档格式。

Windows环境下node --test的隔离子进程报spawn EPERM，改用直接执行测试文件，仍使用node:test断言与测试汇总，没有关闭测试或提高权限。

按用户要求未做截图、浏览器交互或实机视觉验收。没有宣称整关自动通关。HTTP检查确认页面、脚本与图像能获取，不代表浏览器端交互已经验收。

## 用户试玩要点

1. 短按/长按跳跃、跑跳越坑和阶梯落脚。
2. 顶箱获取萝卜、辣椒，检查比例与受伤降级。
3. 踩香菇、缩壳和踢壳，确认碰撞与视觉位置是否一致。
4. 到达中途叶旗后死亡或刷新，核对检查点与分数回滚。
5. 检查像素清晰度、动画抖动、地形接缝和触屏按钮手感。
