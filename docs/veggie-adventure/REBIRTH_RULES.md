# 初始三次重生、额外奖励与游戏结束

2026-10-26：八个世界第一小关各新增一次性“重生＋1”奖励，初始仍为3次，最高储备11次。领奖记录跨死亡、刷新和换关保留，HUD改为“剩余重生 N次”。详见 [REBIRTH_COMBAT_SFX_AND_WARP.md](REBIRTH_COMBAT_SFX_AND_WARP.md)。

2026-10-25，按用户要求取消正常游玩的途中检查点与无限重试。本轮只更新本地测试版本。

## 每局规则

- 从1-1开始新一局时有3次重生机会。这里是初始尝试之外可再重生3次；没有拾取额外奖励时，前三次死亡分别消耗一次，第四次死亡游戏结束。
- 剩余重生次数跨小关继承，过关不自动补次数。八个世界第一小关各有一个重生奖励，每局各可领取一次；HUD显示当前实际储备“剩余重生 N次”。
- 死亡保留约0.7秒动作；有机会时自动从当前小关起点重来，回到基础形态。清除星光、护盾、受伤保护、火弹和敌弹；敌兵、道具、普通方块、首领及倒计时重置，已领取的重生奖励保持已领取。
- 已完成小关和此前累计分数保留，本小关死亡前新增的分数回滚到进入本小关时的分数，避免重生反复刷分。
- 次数为0时仍可继续当前这次尝试；再次死亡后冻结游戏，弹出“游戏结束”，展示止步关卡和总分。
- 游戏结束后暂停键、失焦和继续操作都不会恢复游戏。点击“重新开始”直接从1-1开启新一局，分数、已完成关卡、形态和重生次数一并重置。
- 普通模式不显示或调用调试快照恢复；原“重开本关”改为“重新开始”，不能在后面的关卡免费补满次数。非调试选关限制保持。

## 取消检查点

移除地图叶旗的显示，不再检测或记录途中位置。死亡和重新打开页面都从当前小关入口开始，不从旧旗帜位置复活。

底层快照字段与调试恢复函数暂时保留，用于旧档结构校验和独立验收页；正常死亡流程不调用它们，正常模式也不提供入口。地图原有checkpoint坐标只是兼容旧资料，不参与复活。

## 存档与刷新

存档升级为version 3，记录剩余重生次数、当前小关进入时分数/形态、运行状态和本次死亡是否已获准重生。计数在首次死亡事件立即扣除，多次死亡回调不会重复扣次；死亡状态和复活/结束状态均立即写入浏览器存储。

在死亡动画中刷新：若该次死亡已扣除重生机会，则从当前小关以基础形态开始且不再扣一次；若次数已耗尽且没有获准重生，则直接显示游戏结束。刷新已结束的存档不会补满次数。重新打开正常存档时，从当前小关起点重新开始，沿用该小关开始形态；死亡重生后开始形态为基础形态。

旧版存档第一次迁移时保留所在小关、已完成小关和已记录分数，从入口以基础形态开始，并赋予新规则的3次重生。旧版已完成小关仍自动衔接下一关。
