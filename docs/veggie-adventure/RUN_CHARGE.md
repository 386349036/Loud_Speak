# 一秒起跑与跳跃规则

2026-10-25，多轮运动实验已更新。完整数据及可视化验收见[MOTION_PLAYTEST_20261025.md](MOTION_PLAYTEST_20261025.md)。

无需加速按键：平地连续同向移动约0.5秒达到56px/s、1秒达到112px/s。累积值来自实际水平速度，撞墙不蓄积，蹲行和游泳使用各自控制。松开地面制动约0.35秒、位移19.13px；反向先制动再起跑。空中无输入保留惯性，有输入可修正方向。

三种形态轨迹一致，升级不增加跳跃能力。原地长跳约62.83px、半速70.89px、满速78.69px，满速同高位移96.13px。短按50ms时满速跳高约22.49px。以上为真实Game物理的平地模拟数据，非安全跨坑保底值。

起跳参数在离地时锁定，空中加速不追加跳高。边缘起跳容错75ms、落地前按键缓存100ms；不允许二段跳。上升与下落重力不同，旧版40.43px跳高、90.16px位移已被本轮参数替代。

第一世界四关本轮实际键盘游玩已完成，首领经三次踩踏击败；三形态各自完整人工通关及真实手机多指手感仍待后续验证。仅本地更新。
