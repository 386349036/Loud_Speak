## 战斗规则

主角必须处于下落，并从目标顶部落下；侧碰、向上穿过目标不计为踩踏。显露身体的普通敌兵每次有效踩踏扣1血并将主角向上弹起；缩壳和首领弱点关闭是明确的状态保护。受击闪光本身不增加额外免伤时间。水下仍可踩踏；敌兵火弹命中扣1血，包括缩壳敌兵；首领火弹也必须命中弱点开放期。

| 单位 | 生命与踩踏结果 |
| --- | --- |
| 香菇、水母、椒鱼、玉米投手、捕虫株、云牧者、炮弹兵、跃水椒鱼 | 1血，一次有效踩踏击败 |
| 卷心菜壳兵、核桃甲虫、刺栗守卫 | 2血，第一次有效踩踏缩壳并剩1血；缩壳时踩踏不扣敌我血量，9秒后展开，展开后再踩一次击败；支持侧踢壳体 |
| 飞翼卷心菜 | 3血，先脱翼剩2血，再踩缩壳剩1血；醒转后再次踩中击败 |
| 8位首领 | 6、7、8、8、9、10、10、12血；仅expose弱点期可踩踏或火弹扣血；每次成功命中扣1血并立即关闭弱点进入恢复，生命归零退场 |

多血敌兵显示血条，真正扣血才出现短暂“-1”和受击粒子；缩壳显示“护壳”，挡下踩踏显示火花。首领HUD显示“弱点开放／护甲保护”，绿色顶部标记和弱点倒计时只在可伤窗口显示。受击后的撤离动作、招式预警、选招智能及独立技能冷却保留。非弱点期踩首领不能扣血，身体接触仍可能伤害主角；南瓜受击撤离期间保持原有安全让位。

静止壳被反复踩踏不会重置9秒醒转计时，最后1秒显示展开提示；踩中运动壳会安全踩停，重新进入静止壳。运动壳侧碰仍会伤害主角，静止壳侧碰则踢动；星光状态从顶部踩壳也不绕过缩壳保护。刺栗复用现有收拢轮廓fall和展开unfold动画；本轮未重新生成PNG。

埋在地下、尚未完整出土的捕虫株，以及水中等待跃出的跃鱼，仍是隐藏的非接触状态；其身体显露并参与碰撞后即可踩踏。星光道具及主角受伤保护仍作用于主角。滚壳和星光接触敌兵的原有效果保留。
