# 贴地、无缝地砖、飞行攻击与水底植物修订

2026-10-26，依据用户本地试玩反馈。只更新本地，保留已有修改和原始素材，未提交推送或发布外网。

## 贴地和地砖

检查发现旧W01地形切片是带透明边缘的独立平台，草层顶部与碰撞平面不重合，地层之间也会露出背景；部分动画帧还有1～数个源像素的透明底边。单独平移碰撞体无法解决两个问题。

使用内置imagegen技能生成两张完整材质原图：连续草土表层和循环石土基层，保存在`art-source/veggie-adventure/terrain/seamless-v2/`。完整提示词为[soil-prompt.txt](../../art-source/veggie-adventure/terrain/seamless-v2/soil-prompt.txt)及[stone-prompt.txt](../../art-source/veggie-adventure/terrain/seamless-v2/stone-prompt.txt)。原始旧PNG保留，新运行材质为`assets/terrain/seamless-v2/`的16张世界配色切片，替换各世界Wxx-kit-0/1引用。

运行切片全幅不透明，48×48，采用最近邻缩放及精确边缘配准：表层左右像素逐行一致，基层左右/上下均一致，表层最后一行与对应基层第一行完全一致。生成图本身不是像素级边缘一致性的证明，运行构建器和逐像素测试负责这项约束。源图、配色、运行哈希与规则保存在build-report.json。

动画渲染同时按目标矩形的两个边缘取整，避免只取整起点而使用小数宽高造成浮脚；按26个角色的每帧Alpha轮廓记录footOffsets，把可见底部对齐身体脚底。特效与居中护盾不使用脚底校准，碰撞和跳跃参数不改。移动平台有实色承托，旧透明边缘不会让接触线悬空。校准记录为feet-calibration.json。原图没有被强制改写，用户仍可按实际动作姿态进行视觉验收。

构建：`node tools/veggie-adventure/build-terrain-feedback.cjs`，随后`node tools/veggie-adventure/calibrate-sprite-feet.cjs`。正式动画重建工具也会重新校准脚底。

## 飞行攻击

原飞翼拦截只改变水平目标，纵向始终围绕出生高度摆动；高位飞翼即使锁定主角也无法接触地面角色。现改为观察0.25秒后明确预警0.55秒，锁定二维位置及有限水平预判，随后1.25秒实际俯冲，横向最高112px/s、纵向最高80px/s；不会在俯冲中追改目标。之后2.2秒返回和休息，保留躲避窗口。

实心地形会挡住飞翼，攻击后平滑返回；没有通过瞬间传送进入攻击位置。被踩脱翼时，以当前落点建立地面巡逻区，不跳回旧飞行范围。云牧者仍通过预警投放刺栗攻击，子兵继承安全巡逻范围，保持不同敌兵的攻击区别。

自动检查覆盖三种站立形态被实际俯冲命中、预警后移位躲开、目标锁定、速度边界、返回及脱翼落点连续性，不是人工战斗观感验收。

## 第四世界池底敌兵

新增E13“水葵伏株”，紫红莲苞、青绿水叶与固定根须，1血，可踩踏或火弹击败。池底固定身体，鼓苞预警0.7秒后向锁定位置喷种子，独立冷却3.4秒，喷射后有恢复动作；种子不追踪，离开水池就销毁。
