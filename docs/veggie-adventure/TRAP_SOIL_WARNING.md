# 捕虫株泥土预警与1.5倍尺寸

2026-10-25。根据试玩截图，修正E08豌豆捕虫株从完全不可见状态突然出现的问题。仅更新本地，未提交、推送或发布外网；保留工作区已有音乐导入相关文件。

## 最终表现

- 隐藏期间持续保留一小片隆起的泥土，便于识别埋伏位置。
- 预警时播放四帧透明PNG：平静土堆、轻微鼓起、裂缝扩大、碎土扬起。时长0.6秒。
- 随后0.4秒内，植物本体从地表逐渐升起，地表以下部分裁切；此时仍无接触伤害。
- 完全冒出后才启用原有接触伤害，持续1.4秒；不可踩、可被火弹击败的规则保留。
- 缩回0.4秒时逐渐埋入土中，关闭伤害；隐藏0.8秒后准备下一轮，总周期3.6秒。
- 玩家在附近时继续保持隐藏；已开始的预警不会因玩家靠近而突然跳过或缩短。

E08外观宽高按原尺寸的1.5倍绘制，可见参考高度16→24游戏像素；碰撞框14×14→21×21。保持原中心与地面脚底锚点。所有5处捕虫株（1-2、2-1、6-1、6-3、6-4）采用共用初始化，无需手工改动地图坐标。

放大带有版本标记，检查点恢复不会反复乘1.5；旧版检查点中的捕虫株第一次恢复时转换尺寸并从安全土堆阶段重新开始，避免旧周期直接变成伤害状态。
