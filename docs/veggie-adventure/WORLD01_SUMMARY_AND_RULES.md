## 当前运动与形态基准

| 项目 | 当前基准 |
| --- | --- |
| 水平移动 | 取消独立跑键，普通移动使用run动画；1秒从静止到112px/s |
| 长短跳 | 按起跳速度锁定本次跳跃；长按跳高、松开截断上升；不能空中二段跳 |
| 三形态 | 跳跃能力相同；基础碰撞12×14，成长/辣椒9.6×22.4，蹲下9.6×11.2 |
| 进化比例 | 成长/辣椒图像、碰撞与护盾相对旧版缩小20%；保持脚底及水平中心 |
| 容错 | 边缘起跳75ms，落地前输入缓存100ms |
| 操作 | 键盘方向/跳跃/火弹；手机左单摇杆，右跳跃与火弹 |

本轮用实际Game物理重新测量：原地长跳上升62.83px，半秒助跑70.89px，满速78.69px；满速同高位移96.13px，滞空0.858秒；满速短按50ms跳高22.49px/位移43.87px；松开制动0.35秒/19.13px。这是本项目实测，不是原版马里奥的逐帧数据。复算：`tools/veggie-adventure/measure-motion.mjs`，记录`.publish/rework-current-motion.json`。

| 发现 | 处理 | 后续规则 |

| 移动平台阻挡成长角色 | 后续采用可上穿单向平台 | 保留升降机制，同时避免头顶碰撞夹住大体型 |

## 首领调试结论

南瓜门卫6血；落震、锁定跳扑、瞄准抛射、冲撞按距离/玩家高度/前次招式选择。观察站桩、驻台和实际火弹压力，先预警再行动；预警开始后不追改落点与瞄准。反制有回合冷却，不能连续针对同一习惯。低血量缩短停顿并增加弹数，技能独立冷却不缩短。

| 技能 | 独立冷却 | 应对 |
| --- | --- | --- |
| 落震 | 6.5秒 | 登台或跳过地面波 |
| 跳扑 | 7秒 | 离开锁定落点，利用下穿平台撤离 |
| 瞄准抛射 | 5.5秒 | 在预警后换位，避开预判弹道 |
| 冲撞 | 5秒 | 起跳或登台 |

战场x5520～5808，宽18格，地面连续无死亡坑；三处单向台分别为(5552,176,48)、(5664,160,48)、(5760,176,32)。可向上穿过，下降落台，↓＋跳主动穿下。台面与头部齐平时，弱点取可见头部上沿，避免平台抢先接住玩家导致踩不到。

首领只有expose弱点期可被踩踏/火弹扣血；每次有效命中扣1血并立即进入恢复关闭弱点。真实扣血显示“-1”，护甲阻挡只显示火花。PNG招式预警、中文应对说明、绿色头部标记和倒计时共用逻辑时长。南瓜普通弱点基础2.6秒，低血量2.4秒，高台追击追加回跳时间；受击恢复安全退让，不让玩家刚反击就再次身体受伤。抛射上升穿过单向台、下降才碰台；抛射瞄准边界与首领身体落点边界分别限制。

推广到其他首领时保留各自招式，采用同样的可读预警、固定目标、独立冷却和三形态可达弱点；按实际反击距离延长窗口。水战还要计入58px/s游泳速度，不能直接套陆地112px/s预算。不能把全部首领简单改成南瓜的招式。

## 敌兵、反馈与流程

地面敌兵有发现预警、短时追击、休息和坑边折返；飞翼现已改为0.55秒预警后向锁定的二维位置实际俯冲，1.25秒攻击后返回休息2.2秒，避免只有高处水平巡逻而碰不到主角。捕虫株先泥土隆起再出土，体积为旧版1.5倍。后续试玩已补做两种无缝地形材质、逐帧脚底校准，并在第四世界加入E13底栖水葵；详见[TERRAIN_FLIGHT_AQUATIC_REVIEW.md](TERRAIN_FLIGHT_AQUATIC_REVIEW.md)。

显露身体的敌兵可踩踏扣血；壳兵/核桃/刺栗2血，首次有效踩踏缩壳剩1血。缩壳踩踏只弹起，敌我均不掉血；可侧踢运动壳，顶部踩停安全，9秒醒转，连续踩踏不延长醒转。飞翼3血，依次脱翼、缩壳、醒转后击败。生命归零退场；火弹伤壳仍扣1血。星光不绕过踩壳保护。首领6～12血，阶段保护单独判断。详见[战斗规则](STOMP_AND_SIZE.md)。

普通模式按顺序通关，完成后自动进入下一小关；只在qa=1调试模式可选关。每局额外3次重生，死亡从当前小关入口以基础形态重来，清空本关新增分数和成长；没有途中检查点；次数耗尽后再死游戏结束。重开新局从1-1开始。版本迁移与刷新不得补次数或遗失完成记录。

美术以32-bit时代二维像素为基准，保留透明PNG原件和正式图集；图像、碰撞、脚底锚点分别管理。世界/首领/菜单/状态音乐通过Drive曲目编号匹配，原始音频保留，运行用独立处理副本；无敌结束恢复原配乐位置，暂停/失焦暂停音频。短音乐不等于全部动作音效均完成。
