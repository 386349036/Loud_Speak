# 后续七大Boss战自主可视化检查清单

范围：2-4洋葱矿主、3-4玉米骑士、4-4莲藕潜王、5-4榴莲堡主、6-4辣椒术士、7-4葡萄双生、8-4石榴王。先检查七场、记录截图和复现，再写总结，最后统一修改；不把代码阅读或无界面回归当成可视化验收。不自动提交或发布。

| 编号 | 检查项 | 通过标准 |
| --- | --- | --- |
| B01 | 场地与相机 | 活动区432单位；两端、高低台与水域可利用；主角、Boss及关键预警可见。 |
| B02 | 身份与比例 | 外观、技能与角色主题一致，落脚/朝向/动画/碰撞没有错位或借用错误角色。 |
| B03 | 动作丰富度 | 普通和低血阶段有移动、进攻、防守与恢复变化，不是原地发射或两套换名的同一种攻击。 |
| B04 | 技能差异 | 各Boss有区别于其他Boss的机制；同Boss的技能在轨迹、空间压力或应对方法上确实不同。 |
| B05 | 预警 | 能看懂攻击方向、落点或危险范围，有足够反应时间；图标跟随Boss，不误跟HUD。 |
| B06 | 技能效果 | 危险物和弹体有专属、可辨认的PNG；视觉范围与碰撞一致，不能借用无关籽弹或色块。 |
| B07 | 追击与决策 | 对远近、高处停留、绕后或连续射击能合理反应，不钻台、不卡墙，不连续无解封路。 |
| B08 | 冷却与公平性 | 独立冷却有效；不会无预警连击；同时危险物有上限，保留至少一条可反应的安全路线。 |
| B09 | 弱点 | 开闭明显，只在弱点期扣血；头顶提示正确；初始形态能赶到并正常跳踩，高台不拦截脚底。 |
| B10 | 三形态 | 12×14统一碰撞框正常；成长不改变跳跃能力；初始、成长、辣椒均有可用打法。 |
| B11 | 命中与伤害 | 踩踏、火球、护甲、无伤弹开和击退反馈一致；一次命中不重复扣血；命中后有安全退路。 |
| B12 | 状态衔接 | 待机→蓄力→攻击→弱点→恢复连续；受击/低血/死亡不会残留旧技能状态。 |
| B13 | 胜负流程 | 3次重生、本关重开、击败清场、自动下一关及最终结局符合已有规则。 |
| B14 | 手机可读性 | 横屏控件不遮挡场地/预警/弱点；窄屏镜头不让必躲攻击离开视野。 |
| B15 | 稳定性 | 无控制台错误、资源缺失、无限危险物或明显帧停顿；反复重试不残留对象。 |

每场记录实际操作、位置/形态、至少两类攻击及弱点阶段截图；尽量观察三个完整周期。未能通过正常打法完成的部分标注具体边界。必要时可通过独立调试工具设置战场起点、形态或预览技能，但必须标注为调试补查，不冒称完整通关；不修改正式存档、不强制无敌或直接胜利。

新增技能先明确主题、预警、攻击形态、应对动作、弱点时机、独立冷却和危险物数量上限，再用内置生图生成透明PNG。原有Boss血量及“仅弱点期可扣血”保留。初查七场完成后在`FINDINGS.md`集中归因，随后记录修复与视觉回查证据。
