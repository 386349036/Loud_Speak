# 问题记录格式

问题ID：V32-0001；严重性：P0 / P1 / P2 / P3。

- 标题：一个具体、可复现的问题。
- 类别：CHECKLIST中的编号，可多选。
- 世界/关卡及受影响范围：不要将共用根因重复算成32个独立问题。
- 基线：HEAD、相关工作区修改、素材版本、URL、窗口尺寸。
- 前置条件：形态、强化等级、剩余重生、敌人/Boss状态、时间与位置。
- 复现步骤：实际按键、持续时长、从哪个可达位置开始；是否使用调试定位。
- 预期/实际：分别描述。
- 证据：截图/连续帧相对路径、关键x范围、浏览器错误、可复查状态记录。
- 影响：卡关、误伤、不可读、反馈缺失、性能等；临时绕行是否存在。
- 覆盖缺口：被这个问题阻断的场景；不得标记已通过。
- 根因假设：文件与函数，假设与已证实事实分开。
- 统一修复方案：在32关初查总结后填写。
- 修复文件与测试：修改原因、对应回归、是否涉及新PNG及提示词。
- 回查：原复现步骤、全部受影响关卡、修复前/后截图；状态open / fixed / verified / not_reproduced / blocked。

P0：不能启动/无法完成主线、不可恢复软锁、进度破坏。
P1：正常玩法高概率卡顶/误伤、Boss或敌人攻击/弱点失效、严重显示错误影响判断。
P2：可绕行的布局/动画/素材/操作问题，削弱可读性或体验。
P3：不影响操作的轻微美术或文案瑕疵。

尚未检查或工具无法确认的项目只标`not_verified`，不伪装为已发现或已排除的问题。
