# 场景设计与资产制作

当前进度：八世界40张源图已齐备，32关对应关系见[资产对应表](LEVEL_ASSET_MAP.md)，实际交付及待修整项见[检查记录](SCENE_ASSET_QA.md)。以下首批章节保留设计过程，后续进度以检查记录为准。

## 共用规则

沿用32-bit时代二维像素、晨光苔林和月夜藤园方向。逻辑视口256×240，16单位一格；当前生成源图不等于48像素运行图块。场景分为远景、中景、碰撞地形、非碰撞装饰、前景特效五层；背景绝不承载碰撞。

远景建议视差0.08、中景0.25、地形1.0。这些系数是试验值。太阳/月亮所在远景不循环平铺；透明中景也尚未验证接缝，预览采用有限范围平移。落脚线优先保持清晰；灯具、树根、花草默认无碰撞。尖刺和火焰必须由独立危险对象定义。

## 首批交付

W01和W07各3张：不透明远景、透明中景、透明8构件表。构件表分别包含土台、石台、木桥、三级阶梯、植被、石拱、灯具、树根装饰。完整提示词与生成原图分别归档，不覆盖旧概念图。

预览中的彩色矩形只表示第一关的碰撞布局草案，不是最终地形美术；组件表需要切分、校准平面透视和像素网格后才能填充这些矩形。近景装饰、动态水/火、机关动画以及其余六世界的分层资产仍待制作。
