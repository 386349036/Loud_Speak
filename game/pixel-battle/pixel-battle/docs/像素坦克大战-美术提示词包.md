# 像素坦克大战 - 美术提示词包

> 结论：所有提示词按四段结构书写，「风格锚点」段逐字冻结；一次只变一个变量。第 1 批只出 2 张基准图定锚点，锚点未定稿前不排后面的批。

---

## 一、四段结构（顺序固定）

```
【风格锚点】← 逐字复用，一个字不改
【主体描述】← 每张换
【画布与构图】← 尺寸、朝向、安全边
【技术约束】← 纯色底、边缘干净、无文字
```

**【风格锚点·冻结段 v1】**（每次整段复制粘贴）：

> 16-bit 复古像素风游戏素材，纯俯视正交视角（90 度俯视，能看到顶盖与两侧结构），16×16 逻辑像素网格、色块呈清晰的像素颗粒、硬边无抗锯齿，哑光平涂、每对象 3–4 档明度，统一 1px 深色描边（#0D0D14），剪影粗壮可读，深蓝紫夜色调背景 #1A1A2E，高饱和强调色，无渐变、无光晕、无投影、无写实材质、无任何文字。

## 二、变量槽位表

| 槽位 | 取值 | 更换频率 |
|---|---|---|
| `{对象}` | 坦克 / 砖墙 / 钢墙 / 河道 / 草丛 / 道具图标 | 每张换 |
| `{类别}` | 坦克 / 地形瓦片 / 图标 | 每批换 |
| `{主色}` | 见风格提案色彩板（色号直填） | 同族固定 |
| `{尺寸}` | 生成 512×512 → 后处理量化到逻辑像素 | 同族固定 |
| `{朝向}` | 朝上（全项目固定，其余方向代码旋转） | 全项目固定 |

规则：一次只变一个槽位；同一提示词失败重试不超过 3 次，改描述而非重roll。

## 五、后处理与校验命令

```bash
python art_asset_tools.py keyout <img> --color "#FF00FF"   # 抠透明底
python art_asset_tools.py trim   <dir>                     # 裁透明边
python art_asset_tools.py check  <dir>                     # 规格/命名合规
python art_asset_tools.py sheet  <dir>                     # 接触表（一致性检查）
python art_asset_tools.py palette <img>                    # 提取主色对齐
```

每张生成图必过自检：纯色底无投影、安全边未被裁、无外发光、与锚点线宽/比例/光照一致、缩到 10% 仍可辨认、无文字水印。不过即按「改描述 → 简化主体 → 拆件/人工」三级降级，不重复 roll 超过 3 次。
