## 三、明度阶梯

| 层级 | L（0–100） | 用途 |
|---|---|---|
| 高光 | 80–95 | 钢墙高光边、水面波光、界面金 |
| 主体亮面 | 60–80 | 阵营色亮部、砖面受光 |
| 主体中间调 | 40–60 | 固有色（各阵营主色落此档） |
| 主体暗部 | 20–40 | 阵营暗色 `#AAxxxx` 系列 |
| 背景 | 10–17 | `#1A1A2E` / `#111111` |
| 描边 | 5–10 | `#0D0D14` |

验证方法：任意成品转灰度后，坦克与场地必须一眼可分；砖/钢/水/草四类瓦片灰度下也要能互相区分（草最亮、水最暗的排序不强制，但四者中间调必须错开）。

## 四、与现有实现的衔接（不推翻已上线代码）

1. 画布已开 `image-rendering:pixelated` → 所有源图按**逻辑像素小图**出，引擎放大显示，禁止出"大图假装像素"；
2. 瓦片 T=32 → 地形类源图统一 **16×16 逻辑像素（2 倍显示）**；坦克同理；
3. 4 个阵营坦克同形异色 → **只生成 1 套灰度基准**，4 色由代码染色（一套图四个阵营，省 3/4 产能）；
4. 道具现用汉字「加火盾弹特」→ 替换为 16×16 图标，色号沿用 `POWERUPS` 表；
5. AI 生成 → 量化降采样到逻辑像素 → 后处理入图集，生成图不直接当最终素材。
