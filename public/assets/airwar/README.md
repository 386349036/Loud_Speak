# 云端巡航 · 16-bit 空战素材

此目录提供美术素材。可玩的飞机大战入口是 `/airwar.html`，游戏规则与验证见仓库根目录 AIRWAR_DESIGN.md。生成方式：内置 imagegen。

- `originals/`：每次生成的原始 PNG，保留透明通道。
- `backgrounds/`：三关地貌（360×1080）、远景/云层（360×540）。`*-loop` 为原图与纵向镜像拼接的循环版本；循环首尾像素一致，尺寸为原图高度两倍，禁止按基础图高度截断循环。镜像转折会出现地貌对称，这是消除生成图原始边界接缝的明确取舍。
- `player/`、`enemies/`、`bosses/`：统一机头朝上；游戏可按敌我飞行方向旋转。
- `ammo/`、`items/`：透明 PNG，子弹的装饰外缘不应全部计入伤害范围。
- `effects/`：完整图集及独立帧；帧数、列数、帧率和锚点见 manifest.json。
- `asset-overview.png`：全素材总览。
- `battle-preview-360x540.png`：原始游戏比例的静态战斗合成预览；`battle-preview.png` 是两倍最近邻放大版。不是运行中的游戏截图。
- `seam-check.png`：循环首尾拼接检查。
- `PROMPTS.md`：全部最终提示词。

## 接入约定

逻辑画布 360×540，关闭图像平滑。层级建议：远景→地貌（可轻微降低不透明度以露出远景）→低不透明度云层→道具/飞机→子弹/预警→HUD。背景亮度应低于飞机与危险物。原始图生成大尺寸后以最近邻缩放；透明精灵按内容包围盒统一尺寸，未用几何形状替代任何游戏素材。Boss 完整精灵具有可辨识炮塔/机身/引擎结构，后续制作独立部件时以原始 PNG 为依据，不应把矩形裁片直接当成已去底的独立零件。

## 检查边界

脚本检查全部目标尺寸、真实 alpha、非空动画帧、循环边界一致性及文件哈希；静态预览验证视觉层级。实际移动、碰撞、弹幕难度与动画游戏手感需在实现游戏后另行验收。
