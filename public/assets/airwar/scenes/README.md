# 新场景资产

使用内置 imagegen 独立生成三张原始地貌图：冰川群岛、熔岩裂谷、雨林遗迹。精确提示词见 prompts.json；原图、尺寸、哈希和文件用途见 index.json。

- `*-original.png`：生成原图，保留用于后续制作。
- `*.png`：360×1080 游戏尺寸，以最近邻缩放保留像素边缘。
- `*-loop.webp`：360×2160 无损滚动纹理，由原图和纵向镜像连接；首尾行及中部连接行精确一致。地貌会镜像重复，并非生成器原生无缝。

新场景为单层地貌。原有三个场景继续使用各自远景、地貌、云层。准备和暂停界面的场景选择器可选择全部六种环境；“新景随关卡”按三关分别使用冰川、熔岩、雨林，不增加新关卡或改变碰撞。

运行 `node validate-airwar-scenes.cjs` 验证解码、尺寸和循环连接。原资产库 manifest.json 保持兼容，新增场景使用独立索引。
